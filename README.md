# Crypto Portfolio Tracker

## Description
Crypto Portfolio Tracker is a Python-based application that allows users to manage and track their cryptocurrency holdings. The application fetches real-time price data from the CoinGecko API, and users can add/remove cryptocurrencies from their portfolio, check the value of each holding, and see the total portfolio value in USD.

## Features
- Add/remove cryptocurrencies to/from the portfolio.
- View the current price of each cryptocurrency.
- Calculate and display the total portfolio value in USD.
